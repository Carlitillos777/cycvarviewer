Model

  • Boxes go in as batches (54 by default). The next batch starts only when the current one is fully sorted.
  • Each cycle every remaining box passes the Lead Unstackable Item Filter: one LUIF step per box, plus one step per leading unstackable removed. Empty boxes leave.
  • An empty grouper takes the first item of the first box it sees. After that it takes every box holding that item in any slot. Unclaimed boxes go to the buffer.
  • Slices start only after every box has passed the groupers. Each box costs ceil(items / (stack − 1)) + 1 cart cycles; the extra empty cycle triggers the box swap.
  • A cycle ends when the slowest slice finishes. Partial output boxes leave at cycle end.
  • Randomness: input box order is shuffled per run, buffer order is shuffled per cycle (droppers).
